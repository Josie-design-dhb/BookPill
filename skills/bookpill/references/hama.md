# 《蛤蟆先生去看心理医生》

- **作者：** 罗伯特·戴博德（Robert de Board），英国资深心理咨询师
- **核心主题：** 交互分析（TA）心理学、三种自我状态、人生坐标、情绪自主
- **标签：** `#内耗` `#焦虑` `#情商` `#拖延` `#自我状态` `#童年` `#情绪` `#心理`

## 核心概念

### 三种自我状态（全书核心）

- **定义：** 人一生在三种自我状态间切换——①儿童自我状态（行为感受像小时候，含自然型儿童和适应型儿童）；②父母自我状态（像父母一样评判批评控制，含批判型和养育型）；③成人自我状态（理性冷静客观，能思考决策为自己负责）。
- **适用场景：** 内耗、焦虑、情商
- **具体方法：**
  1. 觉察自己当前处于哪种状态——"我现在是在用儿童状态反应（委屈、愤怒、讨好），还是成人状态回应（冷静、理性、负责）？"
  2. 只有在"成人自我状态"里，人才能真正学习、改变、成长
  3. 当情绪上头时，暂停，深呼吸，问自己："我现在是儿童状态还是成人状态？"
  4. 练习切换到成人状态：用"我观察到……""我选择……""我认为……"的句式替代情绪化反应

### 人生坐标（四种底层信念）

- **定义：** 童年与父母互动形成四种人生坐标——①我不好，你好（自卑自责抑郁）；②我好，你不好（挑剔指责别人）；③我不好，你也不好（绝望厌世）；④我好，你也好（健康自信）。
- **适用场景：** 内耗、焦虑、情商
- **具体方法：**
  1. 识别自己处于哪种人生坐标——蛤蟆的核心困境是长期处于"我不好，你好"
  2. 主动选择新坐标——"我好，你也好"不是感受，而是一生的承诺和行动选择
  3. 每天做一件证明"我好"的小事——完成一个任务、帮助一个人、学一个新东西
  4. 当内心响起"我不够好"的声音时，有意识地反驳："这是旧坐标在说话，不是事实"

### 适应型儿童的生存策略

- **定义：** 为了顺从父母、讨好环境，儿童学会压抑、妥协、道歉、听话。这些策略在童年是生存必需，成年后却变成自我束缚。
- **适用场景：** 内耗、焦虑、情商
- **具体方法：**
  1. 识别自己的讨好模式——当你习惯性道歉、不敢拒绝、过度迎合时，那是"适应型儿童"在操控你
  2. 告诉自己："我已经长大了，不再需要用童年的方式生存"
  3. 练习说"不"——从小事开始，"今天不想去"比"好吧"更健康
  4. 区分"合理的妥协"和"习惯性的讨好"——前者是选择，后者是恐惧

### "软愤怒"的表达方式

- **定义：** 儿童不敢直接对父母发怒，发展出"软愤怒"——内疚、道歉、拖延、无助、悲伤、怄气、优柔寡断。这些看似无害，其实都是压抑的愤怒，最终伤害自己导致抑郁。
- **适用场景：** 内耗、拖延、焦虑
- **具体方法：**
  1. 识别自己的拖延、自责、无助是否是"软愤怒"的表现
  2. 问自己："我在对谁生气？这个愤怒为什么不能直接表达？"
  3. 学会直接、健康地表达愤怒——"我对这件事感到不满"比默默拖延更健康
  4. 不要把愤怒转向自己——自我攻击是"向内投射的愤怒"

### 自我批判的内化

- **定义：** 长大后，人会把"父母的声音"内化为自我批判，不断攻击自己。"没有一种批判比自我批判更强烈。"
- **适用场景：** 内耗、焦虑
- **具体方法：**
  1. 觉察内心的"批判型父母"声音——当你在心里不断骂自己"你真没用""你总是犯错"时，那不是你自己的声音，而是内化的父母声音
  2. 学会用成人状态替代批判型父母状态——"我犯了错，但这不意味着我是废物"
  3. 对自己说一个朋友会对你说的话——"你已经很努力了，犯错是正常的"
  4. 每次自我批判时，记录下来，一周后回看——你会发现这些声音多么不合理

### 情绪自主权

- **定义：** 情绪不是被别人引发的，是你自己选择的。别人无法让你生气或难过，是你选择进入儿童或父母状态才产生情绪。
- **适用场景：** 焦虑、内耗、情商
- **具体方法：**
  1. 不再说"他让我难过"，而是说"我选择如何回应"
  2. 从"被动受害者"变成"主动责任人"
  3. 当感到被激怒时，暂停3秒，问自己："我选择用什么状态回应？"
  4. 情绪是你自己的——别人可以触发，但"如何反应"的决定权在你

### 为人生负责

- **定义：** 咨询的核心转变——蛤蟆意识到必须为自己负责，咨询师不能替他好起来。"必须完成的事情，唯有靠他自己才能完成。"
- **适用场景：** 拖延、内耗、焦虑
- **具体方法：**
  1. 停止等待别人来拯救你——没有人会来
  2. 觉醒永远是孤独的，没有捷径，也无人可替
  3. 从当下的你变成你想成为的自己，必定要经历行为和态度的转变，需要付出艰辛的努力、勇气和决心
  4. 问自己："如果没有任何人能帮我，我现在能做的最小一步是什么？"

### 心理游戏（人生剧本）

- **定义：** 人们在无意识中重复演出的互动模式——"是的，但是……"（求助但拒绝建议）、"看看你让我做了什么"（推卸责任）、"我早就知道会这样"（自我预言）。
- **适用场景：** 内耗、情商
- **具体方法：**
  1. 识别你常玩的心理游戏——你是不是总说"是的，但是……"来拒绝别人的建议？
  2. 觉察游戏背后的"收益"——通过玩这个游戏，你在获得什么？（关注？免责？自我验证？）
  3. 选择退出游戏——"我意识到我一直在说'是的但是'，这次我想真的试试你的建议"
  4. 用成人状态的直接沟通替代心理游戏
