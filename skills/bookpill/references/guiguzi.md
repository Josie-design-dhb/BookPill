## 核心概念

### 捭阖之道（全书总纲）

- **定义：** "捭"为开启、言说、主动出击；"阖"为闭藏、沉默、收敛自保。捭阖是天地万物运行的根本规律，也是所有沟通与博弈的根本法则。
- **适用场景：** 表达、情商
- **具体方法：**
  1. 与人交谈时，"捭以探实情，阖以藏己身"——先读懂人心虚实，再决定开口或沉默
  2. 职场汇报先"阖"听领导需求，再"捭"讲自己方案
  3. 商务谈判先"阖"探对方底线，再"捭"提自己条件
  4. 日常社交中，不确定对方意图时先"阖"（多听少说），摸清情况后再"捭"（精准表达）

### 反应之术（反向试探）

- **定义：** "欲闻其声，反默；欲张，反敛；欲高，反下；欲取，反与。"通过反向试探，让对方暴露真实意图。
- **适用场景：** 表达、情商
- **具体方法：**
  1. **钓语**：抛出话题引诱对方开口——"听说你最近在做XX项目？"让对方主动展开
  2. **象比**：用比喻和事例引导真实想法——"我有个朋友遇到类似情况，他选择了……你觉得他做得对吗？"
  3. **反听**：从字里行间捕捉情绪和需求——不只听对方说了什么，更听他没说什么
  4. 想了解某人真实想法时，不直接问"你怎么想"，而是先说"我觉得这件事可能有这样的问题"，观察对方反应

### 内楗之术（深层连接）

- **定义：** "内"是进献说辞，"楗"是建立牢固连接。说服别人前，先暗中揣摩对方心意，顺应对方意愿建立深层信任。
- **适用场景：** 表达、情商
- **具体方法：**
  1. **投其所好**：找共同话题、共同经历，建立亲近感
  2. **利益绑定**：让对方明白你的建议对他有利，而不是只对你有利
  3. **情感共鸣**：站在对方角度思考，先回应情绪再讲道理
  4. 说服前先问自己："对方最在意什么？我的建议能满足他的哪个需求？"

### 抵巇之术（转危为机）

- **定义：** "巇"是裂缝、漏洞。任何事物出现漏洞时，可堵塞、击退、平息、隐藏或利用；若无法挽救，则推倒重建。
- **适用场景：** 焦虑、内耗
- **具体方法：**
  1. **见微知著**：敏锐发现隐藏的漏洞和危机——小问题出现时不忽视
  2. **防微杜渐**：在问题还小时及时堵住——今天花10分钟修复，胜过明天花10小时救火
  3. **顺势而为**：若无法弥补，则利用它——"既然已经搞砸了，能不能从中找到一个教训/机会？"
  4. 面对焦虑时，把模糊的担忧具体化："到底哪里出了问题？这个裂缝有多大？能补还是该重建？"

### 飞箝之术（赞美与制衡）

- **定义：** "飞"是用赞美让对方放松警惕暴露虚实；"箝"是抓住关键信息从而掌握主动。
- **适用场景：** 表达、情商
- **具体方法：**
  1. 真诚赞美对方最引以为傲之处（非泛泛吹捧）——"你上次那个方案的数据分析做得真细致"
  2. 赞美后再提出你的需求或不同意见——"所以你的判断我一直很信任，但这次有个地方我想讨论一下"
  3. 管理下属/孩子时先"飞"肯定成绩建立好感，再"箝"指出不足提要求
  4. 关键：赞美必须具体、真诚，否则适得其反

### 忤合之术（审时度势）

- **定义：** "忤"是背离，"合"是契合。根据利益关系和形势选择合作或离开，选择比努力更重要。
- **适用场景：** 内耗、焦虑
- **具体方法：**
  1. **自知之明**：清楚自己的能力、优势和底线
  2. **审时度势**：看清大势和各方利益，不逆势而行
  3. **当断则断**：发现不合适及时止损，不沉没成本
  4. 内耗时问自己："我是在'合'（做对的事）还是在'忤'（跟不对的事死磕）？"

### 本经阴符七术（内在修炼）

- **定义：** 包括盛神（精神饱满）、养志（意志坚定）、实意（思想充实）、分威（气场强大）、散势（顺势而为）、转圆（灵活变通）、损兑（去繁从简）七项修炼。只有内心强大，才能应对外界。
- **适用场景：** 内耗、焦虑
- **具体方法：**
  1. **盛神**：保证睡眠和运动，精神饱满是一切的基础
  2. **养志**：明确自己的核心目标，不被外界噪音干扰
  3. **实意**：持续学习和思考，让内在有料可用
  4. **损兑**：减少不必要的信息和选择，专注真正重要的事
