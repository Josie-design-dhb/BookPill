# 纸上良方 BookPill

> 读过的书，终于能用了。

基于 21 本经典书籍的个人问题诊断与建议 AI 技能（Skill）。当你迷茫、焦虑、拖延、内耗、遇到表达或情商困境时，自动从知识库中匹配书中概念，分析原因、拆解问题、给出可执行的建议。

## 它解决什么问题？

读书时看到有启发的内容会划线、记笔记，觉得自己懂了。可真正遇到拖延、焦虑、内耗这些问题时，还是很难想起书里讲过什么，更不知道该用哪一个方法。

**BookPill 就是知识和场景之间的那座桥。**

## 核心能力

- **21 本经典书籍知识库** — 覆盖心理学、哲学、沟通、思维方法等领域
- **5 大问题域精准匹配** — 拖延、焦虑、内耗、表达、情商
- **150+ 个可执行方法** — 每条建议都标注书名和概念名，可回溯原书
- **六步工作流** — 共情开场 → 问题诊断 → 原因分析 → 问题拆解 → 良方输出 → 金句收尾
- **跨平台通用** — 支持 TRAE、ChatGPT (Custom GPT)、Claude (Projects)、WorkBuddy

## 快速开始

### 方式一：TRAE（推荐）

1. 下载本仓库的 `skills/bookpill/` 目录
2. 打开 TRAE IDE → **设置 → 技能与命令**
3. 点击 **创建**，选择 **全局** 或 **项目**
4. 上传 `bookpill-skill.zip`（或手动选择 `SKILL.md`）
5. 确认导入，完成

### 方式二：ChatGPT (Custom GPT)

1. 打开 ChatGPT → **Create a GPT → Configure**
2. **Instructions** 中粘贴 `SKILL.md` 的正文内容（`---` 以下部分）
3. 开启 **Knowledge**，上传 `references/` 下全部 22 个 `.md` 文件
4. 保存即可

### 方式三：Claude (Projects)

1. 打开 Claude → **Projects → Create Project**
2. **Project Instructions** 中粘贴 `SKILL.md` 正文
3. **Project Knowledge** 中上传 `references/` 下全部文件
4. 保存

### 方式四：WorkBuddy（腾讯）

1. 打开 WorkBuddy → 左侧 **技能/插件**
2. 点击 **添加技能 → 上传技能**
3. 上传 `bookpill-skill.zip`
4. 系统自动识别并完成配置

### 方式五：任何支持自定义提示词的 AI

| 文件 | 用途 |
|------|------|
| `SKILL.md` 正文 | 粘贴到系统提示词 / Custom Instructions |
| `references/*.md` | 作为知识库 / 上下文文件上传 |

## 使用方式

安装后无需手动调用，直接在对话中表达情绪信号即可自动触发：

```
我又拖延了，明明知道该做却迟迟不动
最近好焦虑，什么都想做又什么都做不好
好内耗，反复纠结同一件事
不知道怎么跟他沟通，一开口就吵
```

也可以主动提及书名或概念来触发：

```
《被讨厌的勇气》里的课题分离怎么用？
三重大脑是什么意思？
```

## 示例输出

**输入：** 我总是拖延，明明知道该做却迟迟不动，然后又很焦虑

**输出：**

> ## 问题诊断
> 拖延+焦虑的组合，本质上是「启动困难」和「对结果的过度担忧」在互相喂养。
>
> ## 原因分析
> **从《认知觉醒》的视角看：** 你的问题核心是「消除模糊」——拖延不是因为懒，而是因为任务在脑中太「模糊」。本能脑面对模糊任务时自动选择逃避。
>
> **从《蛤蟆先生》的视角看：** 你的拖延可能是一种「软愤怒」——对「被要求做到完美」的无声抗议。
>
> ## 纸上良方
> **良方一：把任务写到纸上，然后只做一个10分钟版本**
> > 出自：《认知觉醒》—— 消除模糊 + 微行动
>
> **良方二：别等"有状态"，先动5分钟再说**
> > 出自：《逆转思维》—— 从行动反推认知
>
> **良方三：问问自己在抗拒什么**
> > 出自：《蛤蟆先生去看心理医生》—— 软愤怒识别

## 扩展知识库

想加新书？两步就行：

1. 在 `references/` 目录下新增一个 `.md` 文件，格式与现有文件保持一致
2. 在 `SKILL.md` 的知识库章节添加引用，在 `problem-index.md` 中补充新书在各问题域的解决路径

skill 会自动将新书纳入匹配范围。

### 知识库文件格式

```markdown
# 《书名》

- **作者：** 作者名
- **核心主题：** 一句话概括
- **标签：** `#标签1` `#标签2`

---

## 核心概念

### 概念名称

- **定义：** 1-2句话
- **适用场景：** 从拖延、焦虑、内耗、表达、情商中选择
- **具体方法：**
  1. 可操作的步骤
  2. ...
  3. ...

---

## 经典语录

1. "语录1"
2. "语录2"
```
